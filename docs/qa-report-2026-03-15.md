## 7. Issues Found

### Issue 1: Stub "Link" Note (Content Quality) — LOW

**Page:** `/link` (also visible in Table view as first row)
**Description:** A note titled "Link" exists with zero content — no description, no author, no tags, no date. It appears in the table as the very first entry with all fields showing "—". The "Mentions (13)" section just matches the word "link" in other notes, which is misleading.
**Impact:** Low — looks like an accidental stub. Clutters the table view.
**Recommendation:** Remove the note or populate it with actual content.

### Issue 2: "Merging Slash Commands into Skills" — Missing Fields (Content Quality) — LOW

**Page:** Table view
**Description:** This article entry has no tags and no consumed date.
**Impact:** Low — incomplete metadata.
**Recommendation:** Add tags and consumed date to the frontmatter.

### Issue 3: Nav Active State Not Always Synced — COSMETIC

**Observation:** After navigating from Graph to Stats, the "Graph" link remained highlighted in the nav bar on the Stats page.
**Impact:** Cosmetic only — doesn't affect functionality.
**Recommendation:** Check the active route matching logic for the nav links.

### Issue 4: Some Podcast Avatars Missing — COSMETIC

**Page:** `/podcasts`
**Description:** Several podcasts (The Databased Podcast, Pragmatic Engineer, Lenny's, Lex Fridman, Better Stack) show a generic podcast icon instead of actual cover art.
**Impact:** Cosmetic — doesn't affect usability.
**Recommendation:** Add podcast cover images where available.
